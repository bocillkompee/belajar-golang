# Belajar Golang

Repository ini berisi project dan latihan untuk belajar **Golang (Go)** dari dasar, mulai dari struktur project, koneksi database, hingga penerapan pola sederhana pada aplikasi Go.

## Yang Dipelajari

* Dasar-dasar Golang
* Package dan module
* Struct dan Entity
* Model
* Controller
* View
* Konfigurasi aplikasi
* Koneksi database
* CRUD
* Struktur project Go

## Struktur Project

```text
belajar-golang/
├── config/
│   └── Konfigurasi aplikasi
├── controllers/
│   └── Logic untuk mengatur request dan proses aplikasi
├── entities/
│   └── Struktur data/entity
├── models/
│   └── Logic yang berhubungan dengan data
├── views/
│   └── Tampilan atau response aplikasi
├── main.go
├── go.mod
└── go.sum
```

## Teknologi

* Go (Golang)
* Go Modules
* Database
* Git & GitHub

## Menjalankan Project

Pastikan Go sudah terinstall di komputer.

Cek versi Go:

```bash
go version
```

Clone repository:

```bash
git clone https://github.com/bocillkompee/belajar-golang.git
```

Masuk ke folder project:

```bash
cd belajar-golang
```

Download dependency:

```bash
go mod tidy
```

Jalankan project:

```bash
go run .
```

## Tujuan

Repository ini dibuat sebagai tempat belajar dan mencoba berbagai konsep Golang, terutama untuk memahami bagaimana Go digunakan dalam pengembangan aplikasi backend.
